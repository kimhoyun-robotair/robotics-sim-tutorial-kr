표면 그리퍼의 네이티브 바인딩에서 상태 자료형을 가져오는 경로입니다.

- `GripperStatus`: `GripperView`가 돌려준 상태 값을 열거형으로 변환합니다.
- `GripperStatus.Closed`: 닫힘 상태와 잡힌 물체 목록을 함께 확인해 실제 부착 여부를 기록합니다.
