# isaacsim.core.utils.viewports

첫 등장: [00번 튜토리얼](../src/00_core_quickstart_isaacsim/TUTORIAL.md) · [run.py:71](../src/00_core_quickstart_isaacsim/run.py#L71)

Isaac Sim 화면에서 장면을 바라보는 카메라 시점을 설정하는 유틸리티이다.

- `set_camera_view(eye=..., target=...)`: 카메라 위치와 바라볼 지점을 정한다.
- 튜토리얼에서는 로봇이나 낙하 물체가 보이도록 초기 관찰 시점을 배치한다.
