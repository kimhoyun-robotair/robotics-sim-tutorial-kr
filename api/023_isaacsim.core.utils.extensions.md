# isaacsim.core.utils.extensions

첫 등장: [06번 튜토리얼](../src/06_python_usd_manual_standalone_python/TUTORIAL.md) · [run.py:46](../src/06_python_usd_manual_standalone_python/run.py#L46)

Isaac Sim 확장을 코드에서 활성화하고 설치 경로를 찾는 함수 모음이다.

- `enable_extension(name)`: URDF importer, ROS 2 bridge, 센서 등의 확장을 이름으로 활성화한다.
- `get_extension_path_from_name(name)`: 확장 폴더를 찾아 포함된 설정 파일이나 예제 에셋 경로를 구성한다.
