# pxr.UsdPhysics

첫 등장: [06번 튜토리얼](../src/06_python_usd_manual_standalone_python/TUTORIAL.md) · [urdf_import.py:32](../src/06_python_usd_manual_standalone_python/urdf_import.py#L32)

강체·충돌체·질량·관절 같은 물리 구조를 USD prim에 정의하고 검사한다.

- `Scene`: 중력 등 물리 장면의 기본값을 설정한다.
- `RigidBodyAPI`, `CollisionAPI`, `MeshCollisionAPI`, `MassAPI`: 물체의 강체·충돌 형상·질량을 다룬다.
- `ArticulationRootAPI`, `Joint`, `FixedJoint`, `RevoluteJoint`, `PrismaticJoint`: 로봇의 링크 연결과 관절 구조를 만들거나 검사한다.
- `DriveAPI`, `MaterialAPI`: 관절 구동값과 마찰·반발계수 같은 물리 재질을 설정한다.
