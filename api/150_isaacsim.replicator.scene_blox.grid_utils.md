SceneBlox 격자 생성에 필요한 공통 도구를 묶은 패키지이며, 튜토리얼에서는 `config`를 가져온다.

- `config.GlobalRNG()`로 SceneBlox가 공유하는 난수 설정에 접근한다.
- `rng`에 시드를 지정한 NumPy 난수 생성기를 넣어 격자 생성의 무작위 선택을 제어한다.
