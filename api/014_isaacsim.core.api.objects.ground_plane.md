# isaacsim.core.api.objects.ground_plane

물체와 충돌하는 평평한 지면을 만드는 GroundPlane 클래스를 제공하는 모듈이다.

- `GroundPlane(prim_path=..., z_position=...)`: USD 경로와 지면 높이를 지정한다.
- 00번 Script Editor 예제에서는 `/World/Quickstart/Ground`에 지면을 직접 생성한다.
