# omni.kit.undo

첫 등장: [13번 튜토리얼](../src/13_python_usd_omniverse_tools/TUTORIAL.md) · [run.py:33](../src/13_python_usd_omniverse_tools/run.py#L33)

Kit 명령으로 만든 편집 이력을 되돌리거나 다시 적용한다.

- `undo()`로 `ChangeProperty`가 바꾼 큐브 색상을 원래 값으로 되돌린다.
- `redo()`로 같은 변경을 다시 적용하고 실제 색상 값으로 결과를 확인한다.
