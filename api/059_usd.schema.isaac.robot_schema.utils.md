# usd.schema.isaac.robot_schema.utils

첫 등장: [29번 튜토리얼](../src/29_python_usd_robot_schema/TUTORIAL.md) · [TUTORIAL.md:51](../src/29_python_usd_robot_schema/TUTORIAL.md#L51)

`utils`는 USD의 Robot Schema 정보를 읽어 로봇의 링크·관절 구성을 조사하는 Python 모듈입니다.

- `GenerateRobotLinkTree(stage, robot)`와 `PrintRobotTree(tree)`로 로봇과 하위 그리퍼의 연결을 출력합니다.
- 튜토리얼은 `GetAllRobotLinks()`, `GetAllRobotJoints()`와 관절 연결·자세를 조사하는 보조 함수도 소개합니다.
- 확장 이름은 `isaacsim.robot.schema`이지만 5.1 예제의 import 경로는 `usd.schema.isaac.robot_schema`입니다.
