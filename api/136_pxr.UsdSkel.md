# pxr.UsdSkel

첫 등장: [160번 튜토리얼](../src/160_events_ext_replicator_agent_customization/TUTORIAL.md) · [retarget_animation.py:4](../src/160_events_ext_replicator_agent_customization/retarget_animation.py#L4)

캐릭터 애니메이션 리타게팅에 전달할 prim의 스켈레톤·애니메이션 타입을 확인한다.

- `Skeleton`: 원본과 대상 스켈레톤 prim의 타입을 `IsA`로 검사한다.
- `Animation`: 원본 애니메이션이 SkelAnimation prim인지 확인한다.
- 검사가 끝나면 별도의 `omni.kit.commands` 명령으로 리타게팅을 요청한다.
