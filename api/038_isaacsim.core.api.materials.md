# isaacsim.core.api.materials

첫 등장: [16번 튜토리얼](../src/16_python_usd_environment_setup/TUTORIAL.md) · [run.py:35](../src/16_python_usd_environment_setup/run.py#L35)

물체의 접촉 특성과 화면에 보이는 외형을 설정할 재질 클래스를 제공한다.

- `PhysicsMaterial`: 정지 마찰·동마찰·반발 계수를 정하고 물체에 적용한다.
- `OmniPBR`: 색상 등의 시각 재질을 만든다. RTX 재질 튜토리얼에서는 이 재질의 Prim에 센서용 비시각 재질 속성도 연결한다.
