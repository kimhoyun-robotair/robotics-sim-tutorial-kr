# omni.graph.nodes

첫 등장: [82번 튜토리얼](../src/82_tools_omnigraph_scripting/TUTORIAL.md) · [TUTORIAL.md:46](../src/82_tools_omnigraph_scripting/TUTORIAL.md#L46)

튜토리얼의 `omni.graph.nodes.*` 이름은 그래프에 생성하는 노드 타입입니다.

- `ConstantString`으로 그래프에서 사용할 문자열 상수를 만듭니다.
- `BreakVector3`로 ROS 2 속도 벡터를 X·Y·Z 값으로 나누어 주행 제어기에 전달합니다.
- `ReadPrimAttribute`로 USD Prim의 속성을 읽어 ROS 2 일반 발행 노드의 입력에 연결합니다.
