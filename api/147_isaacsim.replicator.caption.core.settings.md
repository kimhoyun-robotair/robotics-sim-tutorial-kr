# isaacsim.replicator.caption.core.settings

첫 등장: [171번 튜토리얼](../src/171_events_replicator_caption/TUTORIAL.md) · [generate_scene_graph.py:8](../src/171_events_replicator_caption/generate_scene_graph.py#L8)

`ReplicatorCaptionSettings`는 장면 캡션 생성에 사용할 설정 경로와 대상 카메라를 지정하는 클래스이다.

- `CACHE_CONFIG_FILE_PATH` 설정 키에 준비한 JSON 파일 경로를 저장한다.
- `set_target_camera_prim_path()`로 장면 그래프와 캡션의 기준 카메라를 지정한다.
