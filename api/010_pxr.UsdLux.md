# pxr.UsdLux

첫 등장: [00번 튜토리얼](../src/00_core_quickstart_isaacsim/TUTORIAL.md) · [run.py:73](../src/00_core_quickstart_isaacsim/run.py#L73)

장면과 센서 영상에 필요한 USD 조명을 만들고 밝기·색상·방향을 설정한다.

- `DistantLight`: 한 방향에서 비추는 조명을 만든다.
- `DomeLight`: 장면 전체를 둘러싸는 조명과 환경 텍스처를 설정한다.
- `SphereLight`, `ShapingAPI`: 구형 광원과 빛이 퍼지는 범위를 설정한다.
