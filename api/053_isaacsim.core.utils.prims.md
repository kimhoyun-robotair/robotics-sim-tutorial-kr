# isaacsim.core.utils.prims

첫 등장: [25번 튜토리얼](../src/25_core_core_adding_multiple_robots/TUTORIAL.md) · [handover_task.py:4](../src/25_core_core_adding_multiple_robots/handover_task.py#L4)

USD Prim의 존재 여부를 확인하거나 에셋·변환을 지정해 Prim을 만드는 함수 모음이다.

- `is_prim_path_valid()`: 여러 로봇을 배치할 때 사용할 USD 경로가 이미 존재하는지 확인한다.
- `create_prim()`: 합성 데이터 장면에 지게차·팔레트·상자 USD를 생성하고 위치와 의미 정보를 지정한다.
