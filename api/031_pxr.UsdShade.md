# pxr.UsdShade

첫 등장: [10번 튜토리얼](../src/10_python_usd_open_usd/TUTORIAL.md) · [run.py:33](../src/10_python_usd_open_usd/run.py#L33)

USD 재질과 셰이더를 만들고 물체에 연결한다.

- `Material`, `Shader`: 색상·거칠기·텍스처 같은 외형을 구성한다.
- `MaterialBindingAPI`: 물체에 재질을 연결하거나 기존 바인딩을 확인한다.
- 메시 병합과 로봇 구성 예제에서는 재질 연결을 확인하며, 물리 재질도 바인딩 대상으로 사용한다.
