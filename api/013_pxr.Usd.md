# pxr.Usd

첫 등장: [00번 튜토리얼](../src/00_core_quickstart_isaacsim/TUTORIAL.md) · [run.py:164](../src/00_core_quickstart_isaacsim/run.py#L164)

USD Stage를 열거나 만들고 prim·속성·참조·variant와 편집 대상을 다룬다.

- `Stage.CreateNew`, `Stage.Open`: 튜토리얼에서 사용할 USD 장면을 생성하거나 불러온다.
- `PrimRange`: 로봇·메시·카메라 등의 prim 계층을 순회하고 필요한 대상을 찾는다.
- `EditContext`: 변경 내용을 기록할 레이어나 variant 편집 범위를 지정한다.
- `TimeCode`: 변환·속성 조회에 사용할 시점 또는 기본값을 지정한다.
