# usd.schema.isaac.robot_schema

첫 등장: [29번 튜토리얼](../src/29_python_usd_robot_schema/TUTORIAL.md) · [run.py:37](../src/29_python_usd_robot_schema/run.py#L37)

USD Prim을 로봇, 링크, 관절, 도구 기준점으로 표시하는 Isaac Robot Schema API입니다. 코드에서는 `robot_schema` 또는 `rs`로 가져옵니다.

- `ApplyRobotAPI()`, `ApplyLinkAPI()`, `ApplyJointAPI()`: 로봇 구성요소를 표시합니다.
- `ApplyReferencePointAPI()`, `Attributes`, `Relations`: 도구 기준점, 설명, 축 방향, 링크·관절 관계를 설정합니다.
- `utils.GenerateRobotLinkTree()`, `utils.PrintRobotTree()`: 연결된 링크의 트리 구조를 만들고 출력합니다.
- `CreateSurfaceGripper()`, `Relations.ATTACHMENT_POINTS`: 표면 그리퍼를 만들고 부착용 조인트를 연결합니다.
