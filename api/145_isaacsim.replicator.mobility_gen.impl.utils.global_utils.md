MobilityGen이 공유하는 시뮬레이션 World에 접근하는 도우미 모듈이다.

- `get_world()`로 불러온 시나리오가 사용하는 World를 얻는다.
- 튜토리얼에서는 `get_world().reset()`으로 재생 전에 시뮬레이션을 초기화한다.
