# pxr.PhysxSchema

첫 등장: [06번 튜토리얼](../src/06_python_usd_manual_standalone_python/TUTORIAL.md) · [urdf_import.py:32](../src/06_python_usd_manual_standalone_python/urdf_import.py#L32)

USD 물리 객체에 PhysX 전용 시뮬레이션 설정을 추가하거나 조회한다.

- `PhysxSceneAPI`: 시간 간격, GPU dynamics, 충돌 검출과 solver 설정을 다룬다.
- `PhysxRigidBodyAPI`, `PhysxCollisionAPI`: 강체의 중력 적용과 접촉·충돌 관련 속성을 설정하거나 확인한다.
- `PhysxJointAPI`, `JointStateAPI`, `PhysxArticulationAPI`: 관절 속도·상태와 articulation의 PhysX 속성을 다룬다.
