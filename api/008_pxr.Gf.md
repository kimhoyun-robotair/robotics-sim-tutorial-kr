# pxr.Gf

첫 등장: [00번 튜토리얼](../src/00_core_quickstart_isaacsim/TUTORIAL.md) · [run.py:73](../src/00_core_quickstart_isaacsim/run.py#L73)

USD 속성에 넣을 위치·색상·회전 값과 좌표 변환 계산을 위한 수학 타입이다.

- `Vec3f`, `Vec3d`: 물체의 위치·크기·색상과 중력 방향 같은 3차원 값을 만든다.
- `Quatf`, `Quatd`, `Rotation`: 센서와 로봇 부품의 자세를 표현한다.
- `Matrix4d`, `Transform`: 변환 행렬을 만들거나 위치·회전 값을 꺼낼 때 사용한다.
