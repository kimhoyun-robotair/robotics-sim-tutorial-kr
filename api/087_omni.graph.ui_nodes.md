# omni.graph.ui_nodes

첫 등장: [82번 튜토리얼](../src/82_tools_omnigraph_scripting/TUTORIAL.md) · [create_graphs.py:13](../src/82_tools_omnigraph_scripting/create_graphs.py#L13)

`omni.graph.ui_nodes.PrintText`는 OmniGraph 노드 타입이며, 82번에서 그래프의 실행 여부를 로그로 확인할 때 사용합니다.

- `inputs:text`에 출력할 문자열을, `inputs:logLevel`에 로그 수준을 지정합니다.
- Tick 노드의 실행 신호를 `inputs:execIn`에 연결해 일반 재생 그래프와 수동 평가 그래프를 비교합니다.
