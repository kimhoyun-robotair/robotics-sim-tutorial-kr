초기 Core 튜토리얼에서 Isaac Sim 에셋 루트 경로를 찾을 때 사용하는 import 경로이다.

- `get_assets_root_path()`: Jetbot·Franka 등의 USD 파일 경로를 구성할 기준 위치를 얻는다.
- 튜토리얼은 반환값이 없으면 로컬 USD 경로를 받거나 오류를 알린다.
- 5.1 공식 API 색인은 이 함수의 문서를 `isaacsim.storage.native.nucleus`에 제공하므로 아래 링크는 그 문서로 연결한다.
