# omni.kit.actions.core

첫 등장: [13번 튜토리얼](../src/13_python_usd_omniverse_tools/TUTORIAL.md) · [run.py:31](../src/13_python_usd_omniverse_tools/run.py#L31)

확장 ID와 액션 ID로 Python 동작을 등록하고 실행한다.

- `get_action_registry().register_action()`으로 큐브 색상을 바꾸는 함수를 등록하고 `execute_action()`으로 실행한다.
- `deregister_action()`으로 예제 종료 시 등록한 액션을 정리한다.
- SimReady 예제에서는 기존 `toggle_window` 액션으로 Explorer 창을 연다.
