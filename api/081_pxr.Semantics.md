# pxr.Semantics

첫 등장: [70번 튜토리얼](../src/70_sensors_sensors_physx_lidar/TUTORIAL.md) · [run.py:35](../src/70_sensors_sensors_physx_lidar/run.py#L35)

PhysX LiDAR의 탐지 대상을 구분하도록 prim에 의미 라벨을 기록한다.

- `SemanticsAPI.Apply`: 대상 큐브에 의미 정보 스키마를 붙인다.
- `CreateSemanticTypeAttr("class")`, `CreateSemanticDataAttr`: 라벨 종류와 `target_0` 같은 클래스 이름을 저장한다.
