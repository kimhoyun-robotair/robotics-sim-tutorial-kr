Kit 확장 안에 작은 제어 창과 버튼을 만든다.

- `Window`로 창을 만들고 `VStack` 안에 `Label`·`Button`을 배치한다.
- 버튼 콜백을 장면 생성·카운터 갱신 같은 예제 동작에 연결한다.
- 확장이 종료될 때 만든 창을 정리한다.
