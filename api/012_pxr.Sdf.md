# pxr.Sdf

첫 등장: [00번 튜토리얼](../src/00_core_quickstart_isaacsim/TUTORIAL.md) · [run.py:164](../src/00_core_quickstart_isaacsim/run.py#L164)

USD 파일의 레이어, prim 경로와 속성 자료형을 다루는 기반 API이다.

- `Layer.CreateNew`, `CreateAnonymous`, `FindOrOpen`: 새 레이어를 만들거나 기존 레이어를 불러온다.
- `Path`: prim 관계와 그래프 입력에 사용할 USD 경로를 표현한다.
- `ValueTypeNames`, `AssetPath`: 문자열·수치·색상·에셋 경로 속성의 타입과 값을 지정한다.
- `ChangeBlock`: 여러 레이어 수정을 묶는 데 사용한다.
