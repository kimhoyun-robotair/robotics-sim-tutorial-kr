# pxr.UsdUtils

첫 등장: [12번 튜토리얼](../src/12_python_usd_usd_tools/TUTORIAL.md) · [run.py:33](../src/12_python_usd_usd_tools/run.py#L33)

USD 파일의 에셋 경로를 일괄 수정할 때 사용하는 보조 API이다.

- 현재 튜토리얼에서는 `ModifyAssetPaths`로 레이어 안의 에셋 경로를 순회한다.
- 경로를 고치는 콜백을 전달하고 수정한 레이어를 저장한 뒤, Stage를 다시 열어 결과를 확인한다.
