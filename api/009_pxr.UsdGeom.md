# pxr.UsdGeom

첫 등장: [00번 튜토리얼](../src/00_core_quickstart_isaacsim/TUTORIAL.md) · [run.py:73](../src/00_core_quickstart_isaacsim/run.py#L73)

USD 형상·카메라를 만들고 위치·회전·크기와 장면의 좌표 기준을 다룬다.

- `Cube`, `Sphere`, `Cylinder`, `Mesh`, `Camera`: 튜토리얼의 물체와 카메라 prim을 생성하거나 조회한다.
- `Xform`, `Xformable`, `XformCommonAPI`: prim 계층과 이동·회전·스케일을 설정한다.
- `SetStageMetersPerUnit`, `SetStageUpAxis`: 장면의 길이 단위와 위쪽 축을 정한다.
- `XformCache`, `BBoxCache`, `Imageable`: 월드 변환·경계 상자·표시 상태를 다룬다.
