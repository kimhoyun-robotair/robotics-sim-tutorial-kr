# 용어

| 용어 | 설명 |
| --- | --- |
| SDF | Gazebo world와 model을 기술하는 XML 형식 |
| link | 질량·관성·visual·collision을 갖는 강체 단위 |
| joint | 두 link의 상대 운동을 제한하는 연결 |
| Gazebo Transport | Gazebo 내부의 메시지 통신 계층 |
| DDS | ROS 2가 기본으로 사용하는 통신 미들웨어 계열 |
| bridge | 서로 다른 메시지·통신 계층 사이를 변환하는 노드 |
| TF | ROS 2에서 좌표 프레임 관계를 전달하는 시스템 |
| ECS | 엔티티, 컴포넌트, 시스템으로 simulation 상태와 동작을 구성하는 구조 |
