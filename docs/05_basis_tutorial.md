# Basic Tutorial for Isaac Sim 5.1
Isaac Sim에서는 생각보다 튜토리얼 관련 내용을 풍부하게 제공한다.  
문제는 그게 하도 많고 복잡하고 어려워서 시뮬레이션을 처음 접하는 사람에게는,  
특히 당장 시뮬레이션을 구현해서 써먹고 싶은 사람에게는 "그래서 뭘 어떻게 하라는거지?" 느낌이 될 가능성이 있다.  
따라서 개인적으로 Isaac Sim에서 [가장 먼저 제공해주는 튜토리얼](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/introduction/quickstart_isaacsim.html)의 경우,  
처음에는 가장 기초적인 **GUI 기반 튜토리얼**만 하고 넘어가라고 하고 싶다.  
왜냐하면 Isaac Sim을 처음 보는 입장에서는 Extension이나 Standalone Python에서  
파이썬 문법으로 이래저래 써놓은 것을 봐도 이해하기 어렵기 때문이다.
  
따라서 [**Basic Usage Tutorial**](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/introduction/quickstart_isaacsim.html), [**Basic Robot Tutorial**](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/introduction/quickstart_isaacsim_robot.html) 이렇게 2가지에 대해서만 GUI 기반 간단한 튜토리얼을 하고 넘어가길 추천한다.
