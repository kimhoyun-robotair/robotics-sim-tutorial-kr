# 자주 쓰는 명령어

| 명령 | 설명 |
| --- | --- |
| `gz --commands` | 설치된 Gazebo Tools 하위 명령 목록 |
| `gz sim <world.sdf>` | GUI와 server로 world 실행 |
| `gz sim -s <world.sdf>` | GUI 없이 server 실행 |
| `gz sdf -k <file.sdf>` | SDF 문법·의미 검사 |
| `gz topic -l` | Gazebo Transport 토픽 목록 |
| `ros2 topic list` | ROS 2 토픽 목록 |
| `ros2 pkg list` | ROS 2 package 목록 |

모든 Gazebo 명령은 Harmonic의 `gz` CLI 기준입니다.
